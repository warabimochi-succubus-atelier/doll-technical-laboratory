# どーる技術研究室

## コンセプト

未経験の技法を試し、その結果を記録するための研究室。

記事を書くことを目的にするのではなく、

- 次に試すことを見つける
- 技術の引き出しを増やす
- 制作経験を蓄積する

ことを目的とする。

---

# 基本方針

ドールメイクは

```text
眉毛だけ
アイラインだけ
```

のように部分単位で作業することは少なく、

1回の制作で複数の要素を同時に進めることが多い。

そのため、

> 「今日はどの技法を試してみるか」

を意識しながら制作し、その結果を記録していく。

# 記事について

記事を書くことを目的にしない。

制作ログを続けているうちに

> これはまとめておきたい

と思うテーマがあれば記事化する。

例

- 平行眉研究メモ
- タレ目研究メモ
- 下まぶた表現研究メモ

# トップページ

技法ごとの経験値のようなイメージで表示する。

```text
どーる技術研究室

眉毛       ★★★
アイライン ★★★★
チーク     ★★
まつ毛     ★★★
レジンアイ ★
```

★の数は、

- 試した回数
- 経験量
- 研究の蓄積量

を表す。

分母は表示しない。

> **2026-11 変更**：トップページは運用方針（[policy.md](policy.md)）の研究理念に合わせ、
> 制作ログの感想を「どやぁ（成功）／ぐぬぬ（苦戦）／はて？（疑問）」に分けた延べ数を★で表示する形にした。
> 上のカテゴリ別★は廃止した（技術リストでは技法ごとの試した回数を引き続き表示する）。

# 目標

「今日はメイクするか」

ではなく、

> 「今日はまだやったことのない技法をひとつ試してみるか」

と思える研究室にする。

完成品を増やすだけではなく、

少しずつ技術の引き出しを増やしていくことを目標とする。
